# Mvule Hills Primary School Website

A responsive, single-page website for a fictional English-medium primary school in Dar es Salaam, Tanzania.

**Live demo:** https://cassey-max.github.io/mvule-hills-school/

## Features

- Responsive layout for phone, tablet and desktop, with a mobile menu
- Automatic light and dark mode
- Load animations, scroll reveals, a rotating hero headline and counting statistics
- A "school day" timeline that fills as you scroll
- An auto-rotating testimonial slider
- An event calendar with live countdowns
- A photo gallery and a news section
- An admissions form with client-side validation (front-end demo only)
- Respects the "reduce motion" accessibility setting

## Built with

- HTML5, CSS3 (Grid, Flexbox, custom properties, keyframe animations)
- Vanilla JavaScript (IntersectionObserver, requestAnimationFrame)
- Google Fonts: Bricolage Grotesque and Figtree
- No frameworks or build tools

## Run locally

Download the repository and open `index.html` in any browser.

## Project structure

```
index.html   page content and structure
style.css    design, layout and animations
script.js    interactivity: menu, scroll reveals, counters, slider, countdowns, form
README.md    this file
```

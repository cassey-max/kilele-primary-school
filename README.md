# Kilele Primary School Website

A modern, professional website for a fictional English-medium primary school in Mikocheni, Dar es Salaam, Tanzania. It's designed in a classic school palette of white, navy blue and red.

**Live demo:** https://cassey-max.github.io/kilele-primary-school/

## Features

- Elegant serif and sans-serif typography with a school crest and a "tie stripe" design motif
- Full-screen photo slider with crossfades, a slow zoom effect, animated text, progress bars, pause control and swipe on phones
- Transparent header over the slider that turns white and shrinks on scroll, and highlights the section you're viewing
- Head Teacher's welcome letter with a drop cap and an animated hand-drawn signature
- Curriculum tabs for Pre-Primary, Lower Primary and Upper Primary (keyboard accessible)
- School life gallery in a bento grid with hover captions
- PSLE results section with an animated bar chart and counting numbers
- Testimonial carousel with scroll-snap and arrow controls
- Admissions steps, a 2027 term-dates table and an FAQ accordion
- Contact form with floating labels and validation (front-end demo)
- Fully responsive with a mobile menu, a back-to-top button and "reduce motion" support

## Built with

- HTML5
- CSS3 (Grid, Flexbox, custom properties, clip-path, keyframe animations)
- Vanilla JavaScript (IntersectionObserver, requestAnimationFrame, ARIA tabs and accordion)
- Google Fonts: Young Serif and Manrope

## Project structure

```
index.html   page content and structure

```

## Run locally

Download the repository and open `index.html` in any browser.
